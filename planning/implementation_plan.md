# 블로그 생성기 아키텍처 계획

## 프로젝트 목표
여자친구의 기존 블로그 글 30개 이상을 참고하여, 그녀의 스타일로 새로운 블로그 글을 생성하는 도구를 만듭니다.

## 사용자 환경 및 요구사항
- **하드웨어**: 노트북 (현재 개발용), 집 컴퓨터 (고성능, 추후 활용 가능).
- **숙련도**: 파이썬 초보자.
- **목표**: 효율성과 사용 편의성 (Streamlit 활용).

## 1. 아키텍처 개요

우리는 **RAG (검색 증강 생성)** 또는 **퓨샷 프롬프팅 (Few-Shot Prompting)** 방식을 사용할 것입니다.
어렵고 GPU가 많이 필요한 '모델 학습(Fine-tuning)' 대신, 다음과 같은 방법을 사용합니다:
1.  기존 글 30개 이상에서 텍스트를 추출합니다.
2.  새로운 글을 쓸 때, AI에게 "이런 스타일로 써줘: [예시 글들]"과 함께 주제를 던져줍니다.

### 비교: Ollama (로컬) vs. 외부 API (OpenAI/Gemini)

| 기능 | Ollama (로컬) | 외부 API (Gemini/OpenAI) |
| :--- | :--- | :--- |
| **비용** | 무료 (전기세만) | 저렴함 (텍스트 생성은 쌈) |
| **개인정보** | 100% 내 컴퓨터에 저장 | 클라우드로 데이터 전송됨 |
| **하드웨어** | 좋은 GPU/RAM 필요 | 똥컴/노트북에서도 쌩쌩함 |
| **설치** | 중간 (설치 필요) | 쉬움 (API 키만 있으면 됨) |
| **품질** | 모델에 따라 다름 (Llama3 등) | 매우 높음 (GPT-4/Gemini 1.5) |

**아키텍트의 추천**:
일단 **노트북**에서는 **외부 API (Gemini 또는 OpenAI)**로 시작하세요.
- 노트북 발열이나 속도 걱정 없이 로직을 짤 수 있습니다.
- 로직은 90% 똑같습니다. 나중에 집 컴퓨터에서 코드 한 줄만 바꾸면 Ollama로 바로 전환 가능합니다.

## 2. 폴더 구조

```text
/blog_generator
│
├── .env                # API 키 저장 (절대 공유/업로드 금지)
├── .gitignore          # .env, venv 등 무시할 파일 목록
├── requirements.txt    # 필요한 라이브러리 목록
├── app.py              # Streamlit 메인 화면 (웹사이트)
│
├── modules/
│   ├── __init__.py
│   ├── scraper.py      # extract_blog.py 확장판 (여러 URL 처리)
│   ├── processor.py    # AI가 읽기 좋게 텍스트 다듬기
│   └── llm_client.py   # AI와 대화하는 창구 (Ollama 또는 API)
│
└── data/
    ├── raw/            # 원본 HTML 파일 저장 (백업용)
    └── processed/      # AI에게 먹여줄 깔끔한 텍스트 파일들
```

## 3. 데이터 흐름 (Data Flow)

1.  **입력**: 사용자가 기존 블로그 글 URL들을 입력합니다.
2.  **수집기 (`scraper.py`)**: 
    - HTML을 다운로드합니다.
    - 제목과 본문만 쏙쏙 뽑아냅니다.
    - `data/processed` 폴더에 저장합니다.
3.  **생성기 (Generator)**:
    - Streamlit(`app.py`)에서 주제와 키워드를 입력받습니다.
    - `data/processed`에서 스타일 참고용으로 글 몇 개를 무작위로 가져옵니다.
    - AI에게 **[시스템 프롬프트 + 스타일 예시 + 사용자 주제]**를 보냅니다.
4.  **출력**:
    - AI가 초안을 써줍니다.
    - 사용자가 수정하고 저장합니다.

## 4. 기술 스택

- **언어**: Python 3.10 이상
- **UI 프레임워크**: Streamlit (데이터 앱 만들기에 최고)
- **AI 연동**: `langchain` 또는 직접 API 호출 (`openai`/`google-generativeai` 라이브러리).
- **크롤링 (수집)**: `requests`, `beautifulsoup4` (복잡한 HTML 처리에 `re`보다 좋음).
